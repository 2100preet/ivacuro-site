# IvaCuro – marketing website

Static marketing site for **IvaCuro**, the all-in-one clinic management app for small clinics in India.
Plain HTML/CSS with a little JavaScript (Hindi toggle, pricing switch, mailto demo form): no build step, no tracking.

Live: https://2100preet.github.io/nidaora-site/

* `index.html`: the whole page (SEO/OG tags, JSON-LD)
* `assets/style.css`, `assets/site.js`
* `assets/img/`: optimised app screenshots (WebP), favicon, OG image

**Placeholders to replace before promoting the site:**
* the contact email `hello@ivacuro.in` (in `index.html` and `assets/site.js`)
* the WhatsApp number shown as `+91 XXXXX XXXXX`

This repo contains only the public website. The app code lives in a separate private repository.
